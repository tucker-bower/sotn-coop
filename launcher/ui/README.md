# launcher/ui

The launcher's menus in the game's own style, drawn with art read from the player's disc.

| File | What it does |
|---|---|
| `theme.py` | The look: text in the game's font, its windows and cursor, the pictures. |
| `widgets.py` | The menu toolkit: one loop of input and drawing, lists, the footer, mouse-only links. |
| `sound.py` | Plays the title music and the menu sounds. |
| `textline.py` | A line of typed text with a caret, for every box the player types in; held keys repeat. |
| `screens/` | One file per screen. |
