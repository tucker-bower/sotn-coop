# module

The co-op code that runs inside the game on the PS1.

| File | What it does |
|---|---|
| `arrive.c` | Puts a player somewhere: teleport, respawn, shared pause and joint saves. |
| `arrive.h` | Header for `arrive.c`. |
| `boot.c` | The only co-op code in DRA.BIN: loads the rest of the module from the disc. |
| `boss.c` | Bosses together. |
| `boss.h` | Header for `boss.c`. |
| `character.c` | Which character this game's player is, and loading them. |
| `character.h` | Header for `character.c`. |
| `coop.c` | The hook table DRA jumps through, the mailbox and presence. |
| `coop.ld` | Linker script for the two outputs. |
| `coop_api.h` | The contract between DRA's hooks and the module. |
| `dra_hooks.ld` | Where DRA's hooks jump. |
| `familiar.c` | Draws the partner's familiar on this screen. |
| `familiar.h` | Header for `familiar.c`. |
| `collectibles.c` | Generated by `scripts/gen_collectibles.py`: what each placed collectible's castle flag gives. |
| `flag_gated.c` | Generated by `scripts/gen_flag_gated.py`: entities that read castle flags. |
| `flag_gated.h` | Header for `flag_gated.c`. |
| `link.h` | The game-to-host mailbox; mirrored by `link/mailbox.py`. |
| `Makefile` | Builds `boot.bin` and `COOP.BIN`. |
| `message.c` | On-screen co-op messages. |
| `message.h` | Header for `message.c`. |
| `carry.c` | Hanging onto Bat Alucard, a castle rule. |
| `carry.h` | Header for `carry.c`. |
| `mist.c` | Mist Step: Richter and Maria through mist grates. |
| `mist.h` | Header for `mist.c`. |
| `offhand.c` | Off-hand weapons for Richter and Maria. |
| `offhand.h` | Header for `offhand.c`. |
| `portrait.c` | Richter's and Maria's own name and portrait in the pause menu. |
| `portrait.h` | Header for `portrait.c`. |
| `overlay_table.c` | Generated by `scripts/gen_overlay_table.py`: facts about each stage and boss overlay. |
| `overlay_table.h` | Header for `overlay_table.c`. |
| `partner.c` | The partner as a real second player, run with the game's own player code. |
| `partner.h` | Header for `partner.c`. |
| `progress.c` | Shared progression: detects what's unlocked and applies the partner's. |
| `progress.h` | Header for `progress.c`. |
| `pvp.c` | PvP: each game decides the hits on its own player. |
| `pvp.h` | Header for `pvp.c`. |
| `shared.c` | Shared rooms: the same enemies for both players. |
| `shared.h` | Header for `shared.c`. |
| `solid.c` | Solid entities for a shared room's guest. |
| `solid.h` | Header for `solid.c`. |
| `spells.c` | Alucard's spell shortcuts on the right stick. |
| `spells.h` | Header for `spells.c`. |
| `sprites.c` | Sends this player's sprites and primitives to the partner. |
| `sprites.h` | Header for `sprites.c`. |
| `vram.c` | Replays a room authority's VRAM uploads on the guest. |
| `vram.h` | Header for `vram.c`. |
| `weapons.c` | Draws the partner's hand-weapon swings on this screen. |
| `weapons.h` | Header for `weapons.c`. |
