# characters

Playable characters beyond Alucard, one folder per version of each character.

| File | What it does |
|---|---|
| `maria-dx/` | Co-op Maria: Maria from *Dracula X Chronicles*, built for the PS1, with Alucard's gear and relics. |
| `maria-ultimate/` | Ultimate Maria: SOTN Ultimate's PSP Maria, as that mod plays her, with what co-op needs. |
| `richter-ps1/` | Co-op Richter: Richter from the PS1 game, with Alucard's gear and relics. |
