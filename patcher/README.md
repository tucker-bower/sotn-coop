# patcher

Turns the player's own disc into the co-op disc without shipping game data.

| File | What it does |
|---|---|
| `bps.py` | Makes and applies BPS patches. |
| `collectibles.json` | Where each stage's placed finds are on the disc (offsets only), for `layer.py`. Generated by `scripts/gen_collectibles.py`. |
| `discdiff.py` | **Manual.** Which files and bytes differ between two disc images. |
| `layer.py` | Co-op on top of a modded disc: a three-way merge of retail, the mod and co-op. |
| `modded.py` | Makes a game disc: the player's disc with any number of mods, and co-op layered on top. |
| `mods/hacks.json` | The SOTN Editor hacks we've tested with co-op, as the bytes each writes (made by `harness/make_hack_patches.py`). |
| `ppf.py` | Applies PPF patches, the format the randomizer ships seeds in. |
| `randomizer.py` | Makes the randomized co-op disc from the player's discs, and reads a disc's seed. |
| `patcher.py` | The disc patcher, for players and for release builds. |
| `sectordiff.py` | A disc kept as the sectors that differ from retail: how the launcher keeps a randomized disc. |
| `sectors.py` | CD sector checksums, so a patch never carries them. |
| `test_layer.py` | Checks layering: the collectibles table, a conflicting mod, every built randomizer disc. |
| `test_modded.py` | Checks game discs with several mods: clashes named, the shipped hacks hold no game data. |
| `test_patcher.py` | Checks the patch rebuilds our disc byte for byte. |
