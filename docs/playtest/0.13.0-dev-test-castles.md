# 0.13.0-dev: test castles (2026-10-28)

**Installed on the PC** (silent install). The Thor's APK is `.env/android/SOTN-Coop-0.13.0-dev.apk`, to install when it's plugged in. The PC and the Thor need the same version to play online.

## The test castles
Solo, Couch co-op or Online › Host › **Test castles** (the last item in the castle list). There are 18, in story order:

| Bosses | Scenes |
|---|---|
| Slogra & Gaibon, Doppleganger10, Hippogryph, Minotaur & Werewolf, Lesser Demon, Karasuman, Olrox, Succubus, Scylla, Cerberus, Granfaloon, Richter | Maria in the Alchemy Lab, Maria in the Marble Gallery, Maria in the Royal Chapel, The Librarian, Maria in the Center (the Holy Glasses), The Castle Keep |

- **Progress:** each has a typical player's progress by then (level, gear, relics, earlier bosses beaten). Its line in the list says which way to walk.
- **A fresh copy:** picking one plays a fresh copy, named like `Boss: Olrox_2026-10-28-21:40`, so the test set never changes.
- **The start sticks until you save:** Continue and a reload after both players die put you back at the door. After a save, it's a normal castle.
- **Online:** host one; your partner arrives there too and keeps a copy.
- **Not yet:** the inverted castle.

## Also new
- **Naming:** "New castle" asks for a name. Leave it empty to use the name you type in the game.
- **Join box:** it takes only a room code (or ip:port) from the clipboard, never other text.
- The castle list marks copies of a partner's castle "your partner's".

## What to look for
- A test castle that doesn't start where it says, or whose boss or scene doesn't happen.
- Anything odd at the moment the castle loads and moves you to the door, such as a black screen or a frozen player.
