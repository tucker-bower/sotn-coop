# patches

Our small changes to the pinned upstream projects, applied by `scripts/bootstrap.sh`.

| File | What it does |
|---|---|
| `sotn-decomp.patch` | Adds the co-op hooks to sotn-decomp. |
| `swanstation.patch` | Adds three more VRAM banks (partners' graphics, M17), the widescreen display and 16 MB of RAM (the 8 MB option's 8 MB more, at 0x80800000) to SwanStation. |
